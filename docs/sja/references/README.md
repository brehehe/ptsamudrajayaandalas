# Referensi visual SJA

Empat gambar dalam folder ini adalah acuan visual, bukan aset UI produksi.
Pemetaan tujuan tersedia di inputs.sja.json pada root proyek.
Data transaksi, akun, cuaca, tanggal, dan badge dalam gambar hanya ilustrasi.
Utamakan token status pada docs/sja/DESIGN.md bila warna gambar tidak konsisten.
